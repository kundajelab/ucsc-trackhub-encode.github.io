ChromBPNet Contribution scores (profile)

Description

Profile contribution tracks show projected DeepLIFT/DeepSHAP sequence contribution scores for the model's profile-shape output. These scores highlight bases that contribute to the predicted spatial distribution of signal.

ChromBPNet models are trained on chromatin accessibility assays such as DNase-seq and ATAC-seq. The browser-ready tracks include observed signal, model-predicted signal, bias-corrected predicted signal, contribution scores, selected regions, and motif instance calls where available.

Display Conventions

This faceted composite contains 1512 bigWig subtrack(s) for ChromBPNet sequence contribution scores profile data from ATAC-seq, DNase-seq assays. Subtracks in this composite are hidden by default and can be selected from the faceted table.

The faceted table can be filtered by experiment accession, model accession, assay, target, biosample, tissue, organ, system, strand, score type, and file accession. ENCODE accession columns link back to ENCODE pages where possible.

Methods Summary

Observed signals are generated from high-quality, PCR-deduplicated reads. Model predictions and contribution scores are generated in selected peak regions on hg38. Contribution scores use DeepLIFT/DeepSHAP to attribute model outputs back to input sequence. Motif instances are derived from TF-MoDISco motifs and FiNeMo scans.

Data Access

Each subtrack points to its ENCODE bigWig or bigBed download URL. Use the file accession facet or the item details page to identify and retrieve the underlying ENCODE file.
