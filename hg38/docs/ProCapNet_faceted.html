ProCapNet model tracks

Description

This track displays browser-ready ProCapNet resources from 6 individual ENCODE experiments/models and 42 browser-ready files on the hg38 genome assembly.

ProCapNet models transcription initiation from PRO-cap, CAGE, and RAMPAGE signal. It uses a BPNet-style architecture with additional filters to learn transcription-initiation motifs and higher order interactions, including core promoter motifs. Browser-ready tracks include observed signal, predicted signal, sequence contribution scores, selected regions, and motif instance calls where available.

Observed signal tracks

Experimentally observed signal tracks contain measured PRO-cap transcription-initiation signal used to train and evaluate ProCapNet models. We provide the following tracks:

  • normalized observed signal profile: Normalized experimentally observed base-resolution PRO-cap signal on the plus or minus strand. (bigWig)
  • observed signal profile: Experimentally observed base-resolution PRO-cap signal on the plus or minus strand. (bigWig)

Predicted signal tracks

Model-predicted signal tracks contain denoised ProCapNet predictions in transcription-initiation peak regions on hg38. We provide the following tracks:

  • normalized predicted signal profile: Normalized predicted PRO-cap signal profile in peak regions on the plus or minus strand. (bigWig)
  • predicted signal profile: Predicted PRO-cap signal profile in peak regions on the plus or minus strand. (bigWig)
  • selected regions for predicted signal and sequence contribution scores: Genomic peak regions used to calculate model predictions and contribution scores. (bed, bigBed)

Contribution score tracks

Contribution score tracks show bases that contribute to ProCapNet transcription-initiation predictions, calculated with DeepLIFT/DeepSHAP. We provide the following tracks:

  • counts sequence contribution scores: Projected sequence contribution toward total predicted counts in the region. (bigWig)
  • profile sequence contribution scores: Projected sequence contribution toward predicted signal profile shape. (bigWig)

Genomic instance tracks

Genomic instance tracks identify transcription-initiation-related motif instances discovered from ProCapNet contribution scores with TF-MoDISco and scanned with FiNeMo. We provide the following tracks:

  • sequence motifs instances: browser-ready genomic instance calls of TF-MoDISco motifs in peak regions. (bigBed)

Selected region tracks

Selected region tracks mark the peak regions used to generate model predictions and sequence contribution scores. We provide the following tracks:

  • selected regions for predicted signal and sequence contribution scores: Genomic peak regions used to calculate model predictions and contribution scores. (bed, bigBed)

In total, the composite track includes bigBed, bigWig tracks for observed signal profile, predicted signal profile, sequence contribution scores counts, sequence contribution scores profile, sequence motifs instances.

These datasets provide model outputs and, where available, underlying experimental signals for ENCODE deep learning resources. Additional datasets are available at the ENCODE portal.

Display conventions and configuration

Click a dataset in the faceted table to view available subtracks. Subtracks can be further filtered by experiment accession, model accession, assay, target, biosample, tissue, organ, system, data type, strand, score type, quality-control flag, and file accession. Subtracks in this composite are hidden by default and can be selected from the faceted table.

Observed signals are generated from high-quality, PCR-deduplicated reads. Model predictions are generated in selected peak regions on hg38. Contribution scores use DeepLIFT/DeepSHAP to attribute model outputs back to input sequence. Motif instances are derived from TF-MoDISco motifs and FiNeMo scans.

Data access and use

The ProCapNet data on the UCSC Genome Browser can be explored interactively with the Table Browser or the Data Integrator. For automated download and analysis, each subtrack points directly to an ENCODE bigWig or bigBed file. The data may also be explored interactively using the UCSC REST API. The original data files are available from the ENCODE portal. Clicking any accession in the track's configuration table links directly to the corresponding ENCODE experiment, model, or file details page.

External data users may freely download, analyze and publish results based on any ENCODE data without restrictions. This applies to all datasets, regardless of type or size, and includes no grace period for ENCODE data producers, either as individual members or as part of the Consortium. Researchers using unpublished ENCODE data are encouraged to contact the data producers to discuss possible coordinated publications; however, this is optional. The Consortium will continue to publish the results of its own analysis efforts in independent publications.
