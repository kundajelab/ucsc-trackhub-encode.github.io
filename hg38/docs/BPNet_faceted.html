BPNet model tracks

Description

This track displays browser-ready BPNet resources from 2,339 individual ENCODE experiments/models and 28,068 browser-ready files on the hg38 genome assembly.

BPNet is a lightweight, interpretable, dilated convolutional neural network trained to predict transcription factor binding from TF ChIP-seq signal. One BPNet model is trained per TF ChIP-seq experiment to model a specific transcription factor in a specific cell context. Each model uses a 2,114 bp DNA sequence window, predicts counts and profile outputs for the central 1,000 bp window, and is trained across five chromosome-held-out cross-validation folds. Browser-ready predictions and contribution scores are averaged across folds."

Track types

We provide the following types of tracks using the BPNet model outputs:

Observed signal tracks

Experimentally observed signal tracks contain the measured TF ChIP-seq signal used to train and evaluate BPNet models. BPNet signal is strand-specific because reads accumulate at the 5' end of each strand. We provide the following tracks:

  • normalized observed signal profile: Normalized experimentally observed base-resolution TF ChIP-seq assay signal on the plus or minus strand. This is recommended for visualization and comparison across datasets. (bigWig)
  • observed signal profile: Experimentally observed base-resolution TF ChIP-seq assay signal on the plus or minus strand. (bigWig)

Predicted signal tracks

Model-predicted signal tracks contain denoised BPNet predictions in TF ChIP-seq peak regions on hg38. Predictions are generated independently for each of five fold models and averaged for browser display. We provide the following tracks:

  • normalized predicted signal profile: Normalized predicted TF ChIP-seq signal profile in peak regions on the plus or minus strand. This is recommended for visualization and comparison across datasets. (bigWig)
  • predicted signal profile: Predicted TF ChIP-seq signal profile in peak regions on the plus or minus strand. (bigWig)

Contribution score tracks

Contribution score tracks show how each input base contributes to BPNet predictions, calculated with DeepLIFT/DeepSHAP and averaged across folds for browser-ready tracks. We provide the following tracks:

  • counts sequence contribution scores: Projected sequence contribution toward the total predicted counts in the region. (bigWig)
  • profile sequence contribution scores: Projected sequence contribution toward the predicted signal distribution shape in the region. (bigWig)

Genomic instance tracks

Genomic instance tracks identify motif instances learned from BPNet contribution scores. Motifs are discovered with TF-MoDISco and scanned with FiNeMo. We provide the following tracks:

  • sequence motifs instances: Browser-ready genomic instance calls of TF-MoDISco motifs in peak regions, with human-readable motif names where available. (bigBed)

Selected region tracks

Selected region tracks mark the peak regions used to generate model predictions and sequence contribution scores. We provide the following tracks:

  • selected regions for predicted signal and sequence contribution scores: Genomic peak regions used to calculate model predictions and contribution scores. (bed, bigBed)

In total, the composite track includes bigBed, bigWig tracks for normalized observed signal profile, normalized predicted signal profile, observed signal profile, predicted signal profile, selected regions for predicted signal and sequence contribution scores, sequence contribution scores counts, sequence contribution scores profile, sequence motifs instances.

Display conventions and configuration

Click a dataset in the faceted table to view available subtracks. Subtracks can be further filtered by experiment accession, model accession, assay, target, biosample, tissue, organ, system, data type, strand, score type, quality-control flag, and file accession. 10 subtrack(s) in this composite are enabled by default.

Observed signals are generated from high-quality, PCR-deduplicated reads. Model predictions and contribution scores are generated in selected peak regions on hg38. Contribution scores use DeepLIFT/DeepSHAP to attribute model outputs back to input sequence. Motif instances are derived from TF-MoDISco motifs and FiNeMo scans.

Data access and use

The BPNet data on the UCSC Genome Browser can be explored interactively with the Table Browser or the Data Integrator. For automated download and analysis, each subtrack points directly to an ENCODE bigWig or bigBed file. The data may also be explored interactively using the UCSC REST API. The original data files are available from the ENCODE portal. Clicking any accession in the track's configuration table links directly to the corresponding ENCODE experiment, model, or file details page.

External data users may freely download, analyze and publish results based on any ENCODE data without restrictions. This applies to all datasets, regardless of type or size, and includes no grace period for ENCODE data producers, either as individual members or as part of the Consortium. Researchers using unpublished ENCODE data are encouraged to contact the data producers to discuss possible coordinated publications; however, this is optional. The Consortium will continue to publish the results of its own analysis efforts in independent publications.
