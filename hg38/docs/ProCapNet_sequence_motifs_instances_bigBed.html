ProCapNet Motif instances

Description

Motif instance tracks show genomic instances of de novo sequence motifs learned from contribution scores. Motifs are discovered with TF-MoDISco and scanned with FiNeMo; the browser-ready bigBed combines counts and profile instances at the conservative sensitivity setting.

ProCapNet models are trained on PRO-cap signal and provide browser-ready observed signal, predicted signal, sequence contribution scores, and motif instance calls where available.

Display Conventions

This faceted composite contains 6 bigBed subtrack(s) for ProCapNet sequence motifs instances data from PRO-cap assays. Subtracks in this composite are hidden by default and can be selected from the faceted table.

The faceted table can be filtered by experiment accession, model accession, assay, target, biosample, tissue, organ, system, strand, score type, and file accession. ENCODE accession columns link back to ENCODE pages where possible.

Methods Summary

Observed signals are generated from high-quality, PCR-deduplicated reads. Model predictions and contribution scores are generated in selected peak regions on hg38. Contribution scores use DeepLIFT/DeepSHAP to attribute model outputs back to input sequence. Motif instances are derived from TF-MoDISco motifs and FiNeMo scans.

Data Access

Each subtrack points to its ENCODE bigWig or bigBed download URL. Use the file accession facet or the item details page to identify and retrieve the underlying ENCODE file.
