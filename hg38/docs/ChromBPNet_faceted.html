ChromBPNet model tracks

Description

This track displays browser-ready ChromBPNet resources from 1,512 individual ENCODE experiments/models and 15,111 browser-ready files on the hg38 genome assembly.

ChromBPNet models chromatin accessibility from DNase-seq and ATAC-seq signal. It uses a BPNet-style architecture with additional convolutional filters to learn the complex combinations and spacing of motifs that drive accessibility, plus a separate bias-correction module that models and removes sequence bias introduced by DNase I or Tn5. Browser-ready tracks include observed signal, predicted signal, bias-corrected predicted signal, contribution scores, selected regions, and motif instance calls where available.

Track types

Observed signal tracks

Experimentally observed signal tracks contain measured DNase-seq or ATAC-seq chromatin accessibility signal used to train and evaluate ChromBPNet models. We provide the following tracks:

  • normalized observed signal profile: Normalized experimentally observed base-resolution DNase-seq or ATAC-seq signal. (bigWig)
  • observed signal profile: Experimentally observed base-resolution DNase-seq or ATAC-seq signal. (bigWig)

Predicted signal tracks

Model-predicted signal tracks contain ChromBPNet predictions in accessibility peak regions on hg38. Bias-corrected tracks remove modeled DNase I or Tn5 sequence bias. We provide the following tracks:

  • normalized predicted signal profile: Normalized predicted chromatin accessibility signal profile in peak regions. (bigWig)
  • normalized bias-corrected predicted signal profile: Normalized predicted accessibility signal with the enzyme-bias component removed. (bigWig)
  • predicted signal profile: Predicted chromatin accessibility signal profile in peak regions. (bigWig)
  • bias-corrected predicted signal profile: Predicted accessibility signal with the enzyme-bias component removed. (bigWig)

Contribution score tracks

Contribution score tracks show bases that contribute to predicted accessibility, calculated from the main ChromBPNet model so enzyme-bias contribution is excluded. We provide the following tracks:

  • counts sequence contribution scores: Projected sequence contribution toward total predicted accessibility counts. (bigWig)
  • profile sequence contribution scores: Projected sequence contribution toward predicted accessibility profile shape. (bigWig)

Genomic instance tracks

Genomic instance tracks identify accessibility-related TF motif instances discovered from ChromBPNet contribution scores with TF-MoDISco and scanned with FiNeMo. We provide the following tracks:

  • sequence motifs instances: Browser-ready genomic instance calls of TF-MoDISco motifs in peak regions. (bigBed)

Selected region tracks

Selected region tracks mark the peak regions used to generate model predictions and sequence contribution scores. We provide the following tracks:

  • selected regions for predicted signal and sequence contribution scores: Genomic peak regions used to calculate model predictions and contribution scores. (bed, bigBed)

In total, the composite track includes bigBed, bigWig tracks for bias-corrected predicted signal profile, normalized bias-corrected predicted signal profile, normalized observed signal profile, normalized predicted signal profile, observed signal profile, predicted signal profile, selected regions for predicted signal and sequence contribution scores, sequence contribution scores counts, sequence contribution scores profile, sequence motifs instances.

These datasets provide model outputs and, where available, underlying experimental signals for ENCODE deep learning resources. Additional datasets are available at the ENCODE portal.

Display conventions and configuration

Click a dataset in the faceted table to view available subtracks. Subtracks can be further filtered by experiment accession, model accession, assay, target, biosample, tissue, organ, system, data type, strand, score type, quality-control flag, and file accession. 10 subtrack(s) in this composite are enabled by default.

Observed signals are generated from high-quality, PCR-deduplicated reads. Model predictions are generated in selected peak regions on hg38. Contribution scores use DeepLIFT/DeepSHAP to attribute model outputs back to input sequence. Motif instances are derived from TF-MoDISco motifs and FiNeMo scans.

Data access and use

The ChromBPNet data on the UCSC Genome Browser can be explored interactively with the Table Browser or the Data Integrator. For automated download and analysis, each subtrack points directly to an ENCODE bigWig or bigBed file. The data may also be explored interactively using the UCSC REST API. The original data files are available from the ENCODE portal. Clicking any accession in the track's configuration table links directly to the corresponding ENCODE experiment, model, or file details page.

External data users may freely download, analyze and publish results based on any ENCODE data without restrictions. This applies to all datasets, regardless of type or size, and includes no grace period for ENCODE data producers, either as individual members or as part of the Consortium. Researchers using unpublished ENCODE data are encouraged to contact the data producers to discuss possible coordinated publications; however, this is optional. The Consortium will continue to publish the results of its own analysis efforts in independent publications.
