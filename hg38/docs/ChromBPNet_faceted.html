ChromBPNet model tracks

Description

This track displays browser-ready ChromBPNet resources from 1,512 individual ENCODE experiments and 15,111 files on the hg38 genome assembly. ChromBPNet models chromatin accessibility from DNase-seq and ATAC-seq signal. It uses a BPNet-style architecture with additional convolutional filters to learn the complex combinations and spacing of motifs that drive accessibility, plus a separate bias-correction module that models and removes sequence bias introduced by DNase I or Tn5. Browser-ready tracks include observed signal, predicted signal, bias-corrected predicted signal, contribution scores, selected regions, and motif instance calls where available.

The composite includes bigBed, bigWig tracks for bias-corrected predicted signal profile, normalized bias-corrected predicted signal profile, normalized observed signal profile, normalized predicted signal profile, observed signal profile, predicted signal profile, selected regions for predicted signal and sequence contribution scores, sequence contribution scores counts, sequence contribution scores profile, sequence motifs instances.

The track includes these subtrack types:

  • Signal - a bigWig track containing observed, predicted, bias-corrected, or contribution signal.
  • Region - a bigBed track containing selected regions used for prediction and interpretation.
  • Motif instance - a bigBed track containing motif calls derived from model interpretation outputs.

These datasets provide model outputs and underlying experimental signals for ENCODE deep learning resources. Additional datasets are available at the ENCODE portal.

These resources were generated by a uniform processing workflow: observed signal and training regions were prepared from high-quality reads and matched peak/nonpeak regions; models were trained on experimental signal; denoised predictions were generated from trained models; held-out chromosomes were used for performance evaluation; DeepLIFT/DeepSHAP was used to quantify sequence contribution scores; TF-MoDISco was used to discover high-contribution motifs; and FiNeMo was used to locate motif instances.

Display Conventions and Configuration

Click a dataset in the faceted table to view available subtracks. Subtracks can be further filtered by experiment accession, model accession, assay, target, biosample, tissue, organ, system, data type, strand, score type, quality-control flag, and file accession. 8 subtrack(s) in this composite are enabled by default.

Observed signals are generated from high-quality, PCR-deduplicated reads. Model predictions and contribution scores are generated in selected peak regions on hg38. Contribution scores use DeepLIFT/DeepSHAP to attribute model outputs back to input sequence. Motif instances are derived from TF-MoDISco motifs and FiNeMo scans.

Data Access

The ChromBPNet data on the UCSC Genome Browser can be explored interactively with the Table Browser or the Data Integrator. For automated download and analysis, each subtrack points directly to an ENCODE bigWig or bigBed file. The data may also be explored interactively using the UCSC REST API. The original data files are available from the ENCODE portal. Clicking any accession in the track's configuration table links directly to the corresponding ENCODE experiment, model, or file details page.

bigWig files may also be locally explored using the UCSC tool bigWigToWig. The tool can be used to obtain data confined to a given range, e.g.,

bigWigToWig -chrom=chr8 -start=127898412 -end=127899647 https://www.encodeproject.org/files/ENCFF203WQU/@@download/ENCFF203WQU.bigWig stdout
