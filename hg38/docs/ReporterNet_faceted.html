ReporterNet model tracks

Description

This track displays browser-ready ReporterNet resources from 8 individual ENCODE experiments/models and 16 browser-ready files on the hg38 genome assembly.

ReporterNet models regulatory activity from large-scale reporter assays, including MPRA, lentiMPRA, WG-STARR-seq, and ATAC-STARR-seq. ReporterNet modifies the BPNet-style architecture for shorter sequence windows and reporter-assay outputs, and uses additional convolutional filters. Browser-ready tracks include predicted regulatory activity signal and sequence contribution scores.

Predicted signal tracks

Model-predicted signal tracks contain ReporterNet fold-mean predicted regulatory activity over assayed reporter windows on hg38. We provide the following tracks:

  • predicted signal profile: Predicted reporter activity signal for MPRA, lentiMPRA, WG-STARR-seq, or ATAC-STARR-seq models. (bigWig)

Contribution score tracks

Contribution score tracks show bases that contribute to ReporterNet predicted regulatory activity, calculated for the single predicted-activity output head. We provide the following tracks:

  • counts sequence contribution scores: Projected sequence contribution toward predicted reporter activity. (bigWig)

In total, the composite track includes bigWig tracks for predicted signal profile, sequence contribution scores counts.

These datasets provide model outputs and underlying experimental signals for ENCODE GRAMMAR. Additional datasets are available at the ENCODE portal.

Display conventions and configuration

Click a dataset in the faceted table to view available subtracks. Subtracks can be further filtered by experiment accession, model accession, assay, target, biosample, tissue, organ, system, data type, strand, score type, quality-control flag, and file accession. 12 subtrack(s) in this composite are enabled by default.

Model predictions are generated for assayed reporter windows on hg38. Contribution scores use DeepLIFT/DeepSHAP to attribute model outputs back to input sequence.

Data access and use

The ReporterNet data on the UCSC Genome Browser can be explored interactively with the Table Browser or the Data Integrator. For automated download and analysis, each subtrack points directly to an ENCODE bigWig or bigBed file. The data may also be explored interactively using the UCSC REST API. The original data files are available from the ENCODE portal. Clicking any accession in the track's configuration table links directly to the corresponding ENCODE experiment, model, or file details page.

External data users may freely download, analyze and publish results based on any ENCODE data without restrictions. This applies to all datasets, regardless of type or size, and includes no grace period for ENCODE data producers, either as individual members or as part of the Consortium. Researchers using unpublished ENCODE data are encouraged to contact the data producers to discuss possible coordinated publications; however, this is optional. The Consortium will continue to publish the results of its own analysis efforts in independent publications.
