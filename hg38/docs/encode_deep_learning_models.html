ENCODE Deep Learning Model Tracks

Description

These tracks contain browser-ready ENCODE deep learning model resources on hg38, including observed assay signal, model predictions, selected regions, sequence contribution scores, and motif instance calls.

BPNet models are trained on TF ChIP-seq, ChromBPNet models are trained on DNase-seq or ATAC-seq, and ProCapNet models are trained on PRO-cap. The tracks are organized as faceted composite tracks so experiments, model accessions, biosamples, assay types, targets, tissues, and file accessions can be searched and filtered.

Display Conventions

Signal and contribution score tracks are bigWig files. Region and motif instance tracks are bigBed files. Normalized signal tracks are recommended for visualization and comparison across datasets. For stranded assays, plus and minus strand signal tracks are provided separately.

Data Access

Track data are loaded directly from ENCODE file download URLs. The faceted track tables link experiment, model, and file accessions back to ENCODE where possible.
