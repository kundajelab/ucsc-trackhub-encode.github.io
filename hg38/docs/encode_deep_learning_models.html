ENCODE Deep Learning Model Tracks

Description

This track displays genome-wide ENCODE deep learning model resources from 3,888 individual ENCODE experiments and 43,237 browser-ready files on the hg38 genome assembly. The hub includes observed assay signal, model-predicted signal, bias-corrected predictions where available, selected regions, sequence contribution scores, and motif instance calls from BPNet, ChromBPNet, ProCapNet, ReporterNet models.

The BPNet family contains four related deep learning models of regulatory DNA sequence (sometimes called sequence-to-function models). Each model uses a related BPNet-style convolutional neural network (CNN) architecture to train on, predict, and explain a distinct regulatory functional assay:

  • BPNet: Deep learning model trained on ChIP-seq signal to predict transcription factor binding at base-resolution from DNA sequence.
  • ChromBPNet: Deep learning model trained on chromatin accessibility signal (DNase-seq, ATAC-seq) to predict chromatin accessibility at base-resolution from DNA sequence.
  • ProCapNet: Deep learning model trained on transcription initiation signal (PRO-cap, CAGE, RAMPAGE) to predict transcription initiation signal at base-resolution from DNA sequence.
  • ReporterNet: Deep learning model trained on MPRA signal (MPRA, lentiMPRA, WG-STARR-seq, ATAC-STARR-seq) to predict regulatory activity signal at base-resolution from DNA sequence.

As part of the ENCODE Project, these resources include BPNet models trained on 2,339 TF ChIP-seq experiments across 788 transcription factors and 175 biosamples; ChromBPNet models trained on 1,512 DNase-seq and ATAC-seq experiments across 407 biosamples; ProCapNet models trained on 6 PRO-cap experiments across 6 biosamples; and ReporterNet models trained on lentiMPRA, ATAC-STARR, WG-STARR, and aggregated MPRA datasets across 4 biosamples.

Here, we provide browser-ready tracks of the models' outputs across all models for an easy interactive session. For each model, we generally provide the following types of output tracks:

  • Observed signal: The experimentally observed signal of the assay used to train the model, as a bigWig track.
  • Predicted signal: The model-predicted signal using DNA sequence alone, as a bigWig track.
  • Sequence contribution scores: The importance score of each base in the input DNA sequence that the model used to make its predictions, as a bigWig track.
  • Motif instance: The genomic locations of sequence motifs learned from the model's contribution scores, as a bigBed track.
  • Region: The selected peak regions used to generate model predictions and contribution scores, as a bigBed track.

These resources were generated by processing each model through the same uniform workflow:

  • Preprocess data: Filter peak regions, derive matched nonpeak regions, and convert observed signal tracks into model-ready inputs.
  • Train a model: Train on experimental signal with five chromosome-held-out folds where applicable.
  • Predict signal: Generate denoised model predictions from the trained models.
  • Evaluate performance: Compare observed and predicted signal on unseen test chromosomes using correlation, Jensen-Shannon distance, area under the precision-recall curve, and area under the ROC curve.
  • Quantify sequence contributions: Calculate base-level importance with DeepLIFT/DeepSHAP.
  • Discover sequence features: Aggregate high-contribution sequence patterns into motifs with TF-MoDISco.
  • Locate feature instances: Map motif instances with FiNeMo.

All other non-browser-related files are available at the ENCODE portal.

Display Conventions and Configuration

Click a model collection to view available datasets. Subtracks can be further filtered by experiment accession, model accession, assay, target, biosample, tissue, organ, system, data type, strand, score type, quality-control flag, and file accession. Normalized signal tracks are recommended for visualization and comparison across datasets. For stranded assays, plus and minus strand signal tracks are provided separately.

Data Access

The ENCODE deep learning model data on the UCSC Genome Browser can be explored interactively with the Table Browser or the Data Integrator. For automated download and analysis, each subtrack points directly to an ENCODE bigWig or bigBed file. The data may also be explored interactively using the UCSC REST API. The original data files are available from the ENCODE portal. Clicking any accession in the track's configuration table links directly to the corresponding ENCODE experiment, model, or file details page.
