ENCODE Deep Learning Model Tracks

Description

This track displays genome-wide ENCODE deep learning model resources from 3,151 individual ENCODE experiments and 34,377 browser-ready files on the hg38 genome assembly. The hub includes observed assay signal, model-predicted signal, bias-corrected predictions where available, selected regions, sequence contribution scores, and motif instance calls from BPNet, ChromBPNet, ProCapNet, ReporterNet models.

The BPNet family contains four related deep learning models of regulatory DNA sequence, sometimes called sequence-to-function models. Each model uses a related BPNet-style architecture to train on, predict, and explain a distinct regulatory functional assay:

  • BPNet - transcription factor binding from TF ChIP-seq.
  • ChromBPNet - chromatin accessibility from DNase-seq and ATAC-seq.
  • ProCapNet - transcription initiation from PRO-cap, CAGE, and RAMPAGE.
  • ReporterNet - regulatory activity from MPRA, lentiMPRA, WG-STARR-seq, and ATAC-STARR-seq.

As part of the ENCODE Project, these resources include BPNet models trained on 2,339 TF ChIP-seq experiments across 788 transcription factors and 175 biosamples; ChromBPNet models trained on 1,521 DNase-seq and ATAC-seq experiments across 408 biosamples; ProCapNet models trained on six PRO-cap experiments across six biosamples; and ReporterNet models trained on lentiMPRA, ATAC-STARR, WG-STARR, and aggregated MPRA datasets across three biosamples.

Each model family is uniformly processed through the same high-level workflow:

  • Preprocess data - filter peak regions, derive matched nonpeak regions, and convert observed signal tracks into model-ready inputs.
  • Train a model - train on experimental signal with five chromosome-held-out folds where applicable.
  • Predict signal - generate denoised model predictions from the trained models.
  • Evaluate performance - compare observed and predicted signal on unseen test chromosomes using correlation, Jensen-Shannon distance, area under the precision-recall curve, and area under the ROC curve.
  • Quantify sequence contributions - calculate base-level importance with DeepLIFT/DeepSHAP.
  • Discover sequence features - aggregate high-contribution sequence patterns into motifs with TF-MoDISco.
  • Locate feature instances - map motif instances with FiNeMo.

BPNet models predict transcription factor ChIP-seq signal from DNA sequence.

ChromBPNet models predict chromatin accessibility from DNase-seq or ATAC-seq experiments, with bias-corrected prediction tracks available for many datasets.

ProCapNet models predict PRO-cap signal and expose predicted profile and sequence contribution tracks.

ReporterNet models predict reporter-assay activity from MPRA and STARR assays, with activity predictions, trained model packages, contribution scores, discovered motifs, and motif-instance calls where available.

Observed signal tracks display the measured experimental signal used to train or evaluate the models.

Predicted signal tracks display model outputs across selected genomic regions.

Sequence contribution score tracks identify bases that contribute to the model's counts or profile outputs.

Motif instance tracks identify genomic instances of sequence motifs learned from contribution scores.

ReporterNet resources use the following output categories:

  • Input regions - training and test regions tar files with training, validation, and test regions plus the MPRA training/test data table.
  • Predicted signal - predicted signal profile bigWig files containing fold-mean predicted activity over assayed windows, represented as an unstranded single scalar per window; predicted signal tar files contain per-fold and fold-mean predicted activity in HDF5.
  • Models - models tar files containing per-fold trained ReporterNet models (.h5), the training/test data table, and fold-split JSON files.
  • Contribution scores - counts sequence contribution scores bigWig files containing fold-mean contributions to predicted activity for ReporterNet's single output head; counts contribution tar files contain per-fold and averaged contribution scores in HDF5.
  • Discovered motifs - sequence motifs tar files containing TF-MoDISco motifs from contribution scores, and sequence motifs report tar files containing HTML summary reports.
  • Motif instances - sequence motifs instances tar files containing FiNeMo motif-instance calls across sensitivity thresholds.

The track includes these subtrack types:

  • Signal - a bigWig track containing observed, predicted, bias-corrected, or contribution signal.
  • Region - a bigBed track containing selected regions used for prediction and interpretation.
  • Motif instance - a bigBed track containing motif calls derived from model interpretation outputs.

These datasets provide model outputs and underlying experimental signals for ENCODE deep learning resources. Additional datasets are available at the ENCODE portal.

These resources were generated by a uniform processing workflow: observed signal and training regions were prepared from high-quality reads and matched peak/nonpeak regions; models were trained on experimental signal; denoised predictions were generated from trained models; held-out chromosomes were used for performance evaluation; DeepLIFT/DeepSHAP was used to quantify sequence contribution scores; TF-MoDISco was used to discover high-contribution motifs; and FiNeMo was used to locate motif instances.

Display Conventions and Configuration

Click a model collection to view available datasets. Subtracks can be further filtered by experiment accession, model accession, assay, target, biosample, tissue, organ, system, data type, strand, score type, quality-control flag, and file accession. Normalized signal tracks are recommended for visualization and comparison across datasets. For stranded assays, plus and minus strand signal tracks are provided separately.

Data Access

The ENCODE deep learning model data on the UCSC Genome Browser can be explored interactively with the Table Browser or the Data Integrator. For automated download and analysis, each subtrack points directly to an ENCODE bigWig or bigBed file. The data may also be explored interactively using the UCSC REST API. The original data files are available from the ENCODE portal. Clicking any accession in the track's configuration table links directly to the corresponding ENCODE experiment, model, or file details page.

bigWig files may also be locally explored using the UCSC tool bigWigToWig, which can be compiled from source code or downloaded as a precompiled binary. Instructions for downloading source code and binaries can be found here. The tool can also be used to obtain data confined to a given range, e.g.,

bigWigToWig -chrom=chr8 -start=127898412 -end=127899647 https://www.encodeproject.org/files/ENCFF203WQU/@@download/ENCFF203WQU.bigWig stdout
